ABOUT THE NUMBERS

每一份數據，都有它的時間點。

圖集以 ID 去重；跨模式收藏不重複加總。遊玩與收藏為擷取當時的累計值，不是年度內新增量。曲風與語言按圖集計數；同名歌曲依「曲名＋藝人」區分。

新主創：首次擁有 Ranked／Approved 圖集的年份為 2026，跨模式判斷；Loved 或 GD 經歷不算。國家、新人與搜尋條件均以圖集主創篩選，GD 表再統計該範圍內的客串作者。缺失個人資料保留未知。
